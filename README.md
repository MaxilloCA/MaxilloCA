# Michal Goralski

I'm a pediatric dentist in Ontario, Canada, building software around the work I do every day: reviewing radiographs and writing patient notes.

My projects start with a practical problem in the clinic. I care about responsive interfaces, useful customization, and tools that make repetitive work easier to review and complete.

## Projects

### [RAD Viewer](https://github.com/MaxilloCA/RAD-Viewer)

A desktop radiograph viewer built with Rust, Tauri, React, and TypeScript.

I built RAD Viewer after becoming frustrated with the performance and limited customization of the Carestream software in my own workflow. I wanted more control over how I view, arrange, adjust, and compare images.

### [Consult Note](https://github.com/MaxilloCA/consult-note)

A browser-based consultation note builder extracted from my broader Note Builder project.

I write 40–50 patient notes a day. Open Dental's built-in Auto Notes and Quick Notes were not sufficient for the volume and flexibility I needed, so I built a structured workflow that turns consultation inputs into a note I can review and use.

## How I approach these projects

- Start with a workflow I understand from daily practice.
- Make common actions quick and the resulting output easy to inspect.
- Keep configuration separate from source code.
- Document setup, limitations, and the checks needed before using a tool in a new environment.

These repositories share the implementation and the thinking behind it. Feedback and focused contributions are welcome through each project's issue tracker.
